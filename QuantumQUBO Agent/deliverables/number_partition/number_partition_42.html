Partition Problem

Problem Statement

Given a collection of $N$ positive integers $\{a_0, a_1, \dots, a_{N-1}\}$, the goal is to partition the index set $\{0, \dots, N-1\}$ into two disjoint subsets $\mathcal{S}_0$ and $\mathcal{S}_1$ such that the absolute difference between the sum of the elements in $\mathcal{S}_1$ and the sum of the elements in $\mathcal{S}_0$ is minimized.

Decision Variables

For each index $i \in \{0, \dots, N-1\}$, we introduce a binary decision variable $x_i \in \{0, 1\}$. The variable $x_i$ encodes the assignment of the $i$-th integer $a_i$: $x_i = 1$ indicates that $a_i$ is assigned to subset $\mathcal{S}_1$, while $x_i = 0$ indicates assignment to subset $\mathcal{S}_0$.

Minimizing the absolute difference is equivalent to minimizing its square: \begin{align} \min_{x \in \{0,1\}^N} \left( \sum_{i=0}^{N-1} a_i (2x_i - 1) \right)^2. \end{align} Step 2 --- The problem imposes no structural constraints on the assignment of elements to subsets. Step 3 --- We expand the squared objective directly. Let $C = \sum_{k=0}^{N-1} a_k$ denote the total sum of all integers. Expanding the square yields: \begin{align} \left( \sum_{i=0}^{N-1} a_i (2x_i - 1) \right)^2 &= \sum_{i=0}^{N-1} a_i^2 (2x_i - 1)^2 + \sum_{i \neq j} a_i a_j (2x_i - 1)(2x_j - 1). \end{align} Using the idempotent property of binary variables, $x_i^2 = x_i$, we simplify $(2x_i - 1)^2 = 4x_i^2 - 4x_i + 1 = 1$. The cross terms expand as $(2x_i - 1)(2x_j - 1) = 4x_i x_j - 2x_i - 2x_j + 1$. Substituting these back: \begin{align} H(x) &= \sum_{i=0}^{N-1} a_i^2 + \sum_{i \neq j} a_i a_j (4x_i x_j - 2x_i - 2x_j + 1) \\ &= \sum_{i=0}^{N-1} a_i^2 + 4 \sum_{0 \leq i < j \leq N-1} a_i a_j x_i x_j - 2 \sum_{i \neq j} a_i a_j x_i - 2 \sum_{i \neq j} a_i a_j x_j + \sum_{i \neq j} a_i a_j. \end{align} Collecting the linear terms for each $x_i$, we note that $x_i$ appears in the cross sums whenever $j \neq i$. Thus, the coefficient of $x_i$ is: \begin{align} -2 \sum_{j \neq i} a_i a_j - 2 \sum_{j \neq i} a_j a_i = -4 a_i \sum_{j \neq i} a_j = -4 a_i (C - a_i) = 4a_i^2 - 4C a_i. \end{align} The constant terms combine as $\sum_{i=0}^{N-1} a_i^2 + \sum_{i \neq j} a_i a_j = \left( \sum_{i=0}^{N-1} a_i \right)^2 = C^2$.
