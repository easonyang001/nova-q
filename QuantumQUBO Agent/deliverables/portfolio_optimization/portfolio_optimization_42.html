Cardinality-Constrained Portfolio Selection Problem

Problem Statement

Given a set of $N$ assets indexed by $i \in \{1,\dots,N\}$, each asset $i$ is associated with an expected return score $r_i$. Each distinct pair of assets $(i,j)$ with $1 \le i < j \le N$ is associated with a pairwise risk penalty $c_{ij}$. The task is to select exactly $K$ assets to form a portfolio such that the risk-adjusted score is maximized. The risk-adjusted score is defined as the sum of the expected return scores of the selected assets minus the sum of the pairwise risk penalties between all selected assets.

Decision Variables

For each asset $i \in \{1,\dots,N\}$, we introduce a binary decision variable $x_i \in \{0,1\}$. The variable $x_i$ indicates whether asset $i$ is included in the portfolio, where $x_i = 1$ if asset $i$ is selected and $x_i = 0$ otherwise.

QUBO Derivation

The cardinality constraint requires that exactly $K$ assets are selected: \begin{align} \sum_{i=1}^N x_i = K. \end{align} Step 3. We enforce the constraint via a quadratic penalty term with weight $\lambda > 0$. The penalty is written as: \begin{align} P(x) = \lambda \left( \sum_{i=1}^N x_i - K \right)^2. \end{align} Expanding the square and applying the idempotent property $x_i^2 = x_i$ for binary variables yields: \begin{align} P(x) &= \lambda \left( \sum_{i=1}^N x_i^2 - 2K \sum_{i=1}^N x_i + K^2 + \sum_{i \neq j} x_i x_j \right) \\ &= \lambda \left( \sum_{i=1}^N x_i - 2K \sum_{i=1}^N x_i + K^2 + 2 \sum_{1 \le i < j \le N} x_i x_j \right) \\ &= \sum_{i=1}^N \lambda(1 - 2K) x_i + \sum_{1 \le i < j \le N} 2\lambda x_i x_j + \lambda K^2. \end{align} In standard QUBO matrix notation, the off-diagonal entry $Q_{ij}$ directly represents the coefficient of $x_i x_j$.
