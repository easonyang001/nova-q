Score-Based Bayesian Network Structure Learning with Candidate Parent Sets

Problem Statement

We consider the problem of learning the structure of a Bayesian network over a fixed set of $N$ nodes $\mathcal{N} = \{0, 1, \dots, N-1\}$ with a predefined topological order. For each node $i \in \mathcal{N}$, a finite set of candidate parent sets $\mathcal{C}_i$ is provided, where each candidate set $j \in \mathcal{C}_i$ contains only nodes with indices strictly less than $i$, thereby guaranteeing a directed acyclic graph. Each candidate set $j$ is associated with a score $s_{i,j} \in \mathbb{R}$ and a cardinality $d_{i,j} \in \mathbb{Z}_{\ge 0}$ representing the number of directed edges it introduces. The objective is to select exactly one candidate parent set for every node such that the total number of directed edges in the resulting network equals a prescribed integer $K$, while maximizing the sum of the scores of the selected sets.

Decision Variables

For each node $i \in \mathcal{N}$ and each candidate parent set $j \in \mathcal{C}_i$, we introduce a binary decision variable $x_{i,j} \in \{0,1\}$. The variable $x_{i,j}$ takes the value $1$ if and only if candidate parent set $j$ is selected for node $i$, and $0$ otherwise. The full decision vector is $\mathbf{x} = (x_{i,j})_{i \in \mathcal{N}, j \in \mathcal{C}_i}$.

QUBO Derivation

Step 1 --- Objective. We convert the maximization problem to a minimization problem by negating the objective function: \begin{align} \min_{\mathbf{x}} \left( -\sum_{i \in \mathcal{N}} \sum_{j \in \mathcal{C}_i} s_{i,j} x_{i,j} \right). \end{align} Step 2 --- Constraints. The problem is subject to two equality constraints: \begin{align} \sum_{j \in \mathcal{C}_i} x_{i,j} &= 1, \quad \forall i \in \mathcal{N}, \\ \sum_{i \in \mathcal{N}} \sum_{j \in \mathcal{C}_i} d_{i,j} x_{i,j} &= K. \end{align} Step 3 --- Penalty Terms. We incorporate these constraints into the objective using quadratic penalty terms with weight $\lambda > 0$: \begin{align} H_{\text{pen}}(\mathbf{x}) &= \lambda \sum_{i \in \mathcal{N}} \left( \sum_{j \in \mathcal{C}_i} x_{i,j} - 1 \right)^2 + \lambda \left( \sum_{i \in \mathcal{N}} \sum_{j \in \mathcal{C}_i} d_{i,j} x_{i,j} - K \right)^2. \end{align} Expanding the first term using the idempotent property $x_{i,j}^2 = x_{i,j}$ for binary variables: \begin{align} \lambda \sum_{i \in \mathcal{N}} \left( \sum_{j \in \mathcal{C}_i} x_{i,j} - 1 \right)^2 &= \lambda \sum_{i \in \mathcal{N}} \left( \sum_{j \in \mathcal{C}_i} x_{i,j}^2 + 1 - 2 \sum_{j \in \mathcal{C}_i} x_{i,j} \right) \nonumber \\ &= \lambda \sum_{i \in \mathcal{N}} \left( \sum_{j \in \mathcal{C}_i} x_{i,j} + 1 - 2 \sum_{j \in \mathcal{C}_i} x_{i,j} \right) \nonumber \\ &= \lambda \sum_{i \in \mathcal{N}} \left( 1 - \sum_{j \in \mathcal{C}_i} x_{i,j} \right). \end{align} Expanding the second term: \begin{align} \lambda \left( \sum_{i \in \mathcal{N}} \sum_{j \in \mathcal{C}_i} d_{i,j} x_{i,j} - K \right)^2 &= \lambda \left( \sum_{i \in \mathcal{N}} \sum_{j \in \mathcal{C}_i} d_{i,j}^2 x_{i,j} + K^2 - 2K \sum_{i \in \mathcal{N}} \sum_{j \in \mathcal{C}_i} d_{i,j} x_{i,j} + \sum_{(i,j) \neq (k,l)} d_{i,j} d_{k,l} x_{i,j} x_{k,l} \right). \end{align} Step 4 --- Combined Hamiltonian. The total QUBO Hamiltonian $H(\mathbf{x})$ is the sum of the negated objective and the penalty terms: \begin{align} H(\mathbf{x}) &= -\sum_{i \in \mathcal{N}} \sum_{j \in \mathcal{C}_i} s_{i,j} x_{i,j} + \lambda \sum_{i \in \mathcal{N}} \left( 1 - \sum_{j \in \mathcal{C}_i} x_{i,j} \right) + \lambda \left( \sum_{i \in \mathcal{N}} \sum_{j \in \mathcal{C}_i} d_{i,j}^2 x_{i,j} + K^2 - 2K \sum_{i \in \mathcal{N}} \sum_{j \in \mathcal{C}_i} d_{i,j} x_{i,j} + \sum_{(i,j) \neq (k,l)} d_{i,j} d_{k,l} x_{i,j} x_{k,l} \right). \end{align} Step 5 --- Q Matrix Entries and Offset. Collecting linear and quadratic coefficients, we obtain the QUBO form $H(\mathbf{x}) = \sum_{i,j} Q_{i,j} x_{i,j} + \sum_{(i,j) < (k,l)} 2 Q_{(i,j),(k,l)} x_{i,j} x_{k,l} + c$. The entries are given by: \begin{align} Q_{i,j} &= -s_{i,j} - \lambda + \lambda d_{i,j}^2 - 2\lambda K d_{i,j}, \quad \forall i \in \mathcal{N}, j \in \mathcal{C}_i, \\ Q_{(i,j),(k,l)} &= \lambda d_{i,j} d_{k,l}, \quad \forall (i,j) \neq (k,l), \\ c &= \lambda N + \lambda K^2. \end{align}

Penalty Weight Justification

Let $S_{\max} = \max_{i,j} |s_{i,j}|$. The maximum possible gain in the objective function from flipping a single variable $x_{i,j}$ is bounded by $2 S_{\max}$. Violating the first constraint by one unit changes the penalty by at least $\lambda$. Violating the second constraint by one unit changes the penalty by at least $\lambda (2K+1)$ in the worst case. To ensure that any infeasible solution has strictly higher energy than the best feasible solution, we require $\lambda > S_{\max} + \lambda \cdot (\text{max constraint violation impact})$. A sufficient condition is $\lambda > \sum_{i,j} |s_{i,j}| + \lambda \cdot (2K D_{\max} + D_{\max}^2)$, where $D_{\max} = \max_{i,j} d_{i,j}$. In practice, choosing $\lambda > \max_{i,j} |s_{i,j}|$ ensures that the penalty cost for any constraint violation strictly exceeds the maximum achievable objective improvement, thereby forcing the optimizer to satisfy all constraints. For typical normalized scores bounded by $|s_{i,j}| < 100$, setting $\lambda = 1000$ guarantees this dominance.

Correctness Argument

Minimizing $H(\mathbf{x})$ over $\{0,1\}^n$ recovers the optimal solution because the penalty terms are non-negative and vanish exactly on the feasible set defined by the one-parent-set and total-edge constraints. For any feasible assignment, $H(\mathbf{x})$ reduces to the negated objective function, so the global minimum corresponds to the maximum score. For any infeasible assignment, at least one constraint is violated, incurring a positive penalty. By choosing $\lambda$ sufficiently large, the energy increase from constraint violation strictly dominates any potential reduction in the objective function, ensuring that the global minimum cannot be infeasible. Thus, the unconstrained QUBO minimum is guaranteed to be feasible and optimal for the original constrained problem.

Enumerating the $2^3=8$ feasible assignments (one per node), we check edge counts and scores:

  • $\mathbf{x} = (0,1,0,1,1,0)$: edges $1+0+1=2$, score $20+5+30=55$. $H = -55 + 0 + 7000 = 6945$.
