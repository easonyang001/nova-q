# 真實資料全景：來源、存取方式與常見資料情況

本文件是系統處理「任意真實問題」時的資料參考：Data Scout 依此決定去哪裡找，Data Adapter 依此判斷資料屬於哪種情況、
用哪個前處理工具處理。標示「✓ 已實測」者為 2026-10-11 實際連線確認可用。

核心原則：**不一個一個網站去接，而是照「平台類型」與「資料情況」去接**。全世界多數開放資料平台建立在少數幾種系統上，
支援一種系統就等於支援所有用它架設的平台；資料的情況也是有限的幾類，每類一個經測試的工具。

---

## 一、資料分類：每個欄位屬於哪一類（決定系統怎麼做）

| 類別 | 定義 | 例子 | 系統行為 |
|---|---|---|---|
| **A 公開資料** | 網路上找得到的客觀事實 | 地點座標、人口、現有設施、道路距離、法規、股價歷史 | 自動搜尋、下載、前處理；找不到要明說，**不可編造** |
| **B 使用者設定** | 決策者的偏好或參數，本來就不是「資料」 | 停留時間、天數、預算、要蓋幾座、權重 | 問使用者，給合理預設值可修改 |
| **C 私人資料** | 只有使用者有的內部資料 | 員工名單、可上班時間、公司訂單、內部成本 | 使用者上傳；沒有就用 **mock 資料並明確標示** |

## 三、常見資料情況與處理方式

每一列是一種「情況」：怎麼偵測、用哪個工具處理。工具位於 `qubo_auto/annealing/prep/`（逐步實作）。

### 3.1 取得資料時

| 情況 | 偵測 | 處理 |
|---|---|---|
| 需要 API 金鑰 | 401/403 或文件說明 | 金鑰放 `.env`；沒有時改用替代來源或請使用者申請 |
| 頻率限制、伺服器忙碌 | 429、503、504 | 退避重試、換鏡像、快取 |
| 分頁 | 回應有 next、offset、`$top` | 自動翻頁直到上限 |
| 檔案很大 | Content-Length | 大小上限、串流、只取需要的欄位或區域 |
| 連結失效 | 404 | 標記失效，回到搜尋 |
| 憑證、網路問題 | SSL、IPv6 錯誤 | 已處理：台灣政府憑證、只走 IPv4 |
| 同一份資料要重複用 | — | 下載快取（網址＋日期） |

### 3.2 檔案格式與編碼

| 情況 | 處理 |
|---|---|
| CSV／TSV、Big5／CP950、UTF-8 BOM | 已處理：自動判斷編碼與分隔符號 |
| Excel 多工作表、合併儲存格、多列表頭 | 表頭偵測、展開合併儲存格、多列表頭壓成一列 |
| JSON 巢狀、API 包裝（`{"result": {"records": [...]}}`） | 自動找出記錄陣列並攤平 |
| GeoJSON | 已處理：點座標、多邊形取中心 |
| Shapefile（zip） | 已處理：屬性＋中心點，保留 .prj 座標系統 |
| KML／KMZ、GPX | 待實作：解析成點或線 |
| XML | 待實作：找重複節點轉成表格 |
| PDF 表格 | 盡量避免；必要時抽表格，品質不保證 |
| ODS、Parquet | pandas 直接讀 |

### 3.3 表格結構

| 情況 | 例子 | 處理 |
|---|---|---|
| 總計、小計列 | 「總計」「合計」「全區」 | 偵測並移除，避免重複計算 |
| 按類別拆開的列 | 性別 計／男／女 | 只留「計」，或依需求轉成欄位 |
| 寬表與長表 | 每個月一欄 | 寬轉長或長轉寬 |
| 表頭不在第一列、說明文字混在表內 | 政府 Excel 常見 | 偵測真正的表頭列 |
| 重複資料 | 同一設施出現兩次 | 依鍵值或座標去重 |
| 多個年度或月份分成多個檔案 | 每月一檔 | 合併，加上時間欄位 |

### 3.4 數值與文字

| 情況 | 例子 | 處理 |
|---|---|---|
| 數字是文字 | 「1,234」「12.5%」「NT$300」 | 轉成數字並保留單位 |
| 缺值記號 | 「-」「—」「…」「NA」「x」「*」 | 統一成缺值 |
| 全形與半形 | 「１２３」「（）」 | 正規化 |
| 台／臺、異體字 | 「台北市」與「臺北市」 | 名稱正規化 |
| 單位不一 | 公尺與公里、千元與元 | 依欄位名稱與數值範圍判斷並換算 |
| 民國年 | 「113年7月」「1130731」 | 轉西元日期 |
| 時區與時間格式 | UTC 與本地時間 | 統一時區 |

### 3.5 地理資訊

| 情況 | 處理 |
|---|---|
| 座標系統不同：TWD97 TM2（EPSG:3826）、TWD67、WGS84、Web Mercator | 偵測（數值範圍、.prj）後統一轉成 WGS84 經緯度 |
| 經緯度欄位對調 | 依國家範圍檢查並自動修正 |
| 只有地址沒有座標 | 地理編碼（Nominatim，含快取與限速），回報失敗的地址 |
| 只有行政區名稱 | 以行政區界圖的中心點代表 |
| 多邊形資料（區域） | 中心點、面積、點是否落在區域內 |
| 需要距離 | 直線距離（haversine）或道路距離與時間（OSRM 矩陣） |
| 需要「範圍內」的點 | 依地名取範圍框（Nominatim），或用行政區多邊形篩選 |
| 地圖資料覆蓋不完整 | OSM 在台灣的設施數偏少：與政府資料交叉比對並回報覆蓋率 |

### 3.6 多份資料接在一起

| 情況 | 處理 |
|---|---|
| 名稱寫法不同 | 正規化後比對；模糊比對；回報對不上的筆數與名單 |
| 行政區代碼與名稱並存、代碼版本不同（區域調整） | 優先用代碼；對不上時用名稱；回報差異 |
| 空間接合 | 點落在哪個區域；最近鄰；距離範圍內 |
| 時間對不齊 | 對齊到同一期間，取最新或平均 |

### 3.7 規模與品質

| 情況 | 處理 |
|---|---|
| 資料太多，超過 QUBO 能好好解的規模 | 依目標硬體決定上限，以分群挑代表點、行政區聚合、篩選地區；**說明怎麼縮的**，不得只取前 N 筆 |
| 缺值多 | 回報缺值率；決定刪除、補值或改用其他來源 |
| 異常值 | 依範圍或統計偵測並回報 |
| 資料過舊 | 回報更新日期 |
| 授權 | 記錄授權條款（政府資料開放授權、ODbL、CC BY…），成果說明中標註來源 |

## 四、每次處理都要產出的紀錄

1. **資料需求表**：每個模型欄位的類別（A/B/C）、來源、覆蓋率、真實或估計。
2. **前處理紀錄**：每一步做了什麼、筆數變化、刪掉或補了什麼。
3. **來源清單**：資料集名稱、發布機關、網址、下載日期、授權。
