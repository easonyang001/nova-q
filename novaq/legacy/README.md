# Legacy: text-to-QUBO benchmark front end

`benchmarks/` (100 textbook QUBO problems with sample test cases) and `deliverables/` (the reports generated for
them) come from the earlier text-to-QUBO front end this project grew out of (QuantumQUBO Agent, MIT License). NOVA-Q
does not use them; they are kept so that `scripts/run_benchmark_suite.py`, `scripts/run_single.py` and the ablation
scripts still run.
