Problem Statement

Given a graph and a set of $K$ candidate community partitions, each associated with a precomputed modularity-like quality score $S_k$, the task is to select exactly one partition that maximizes the overall community quality. The selection must satisfy the requirement that precisely one candidate is chosen, and the objective is to return the optimal partition along with its maximum score.

Decision Variables

For each candidate partition $k \in \{0, 1, \dots, K-1\}$, introduce a binary decision variable $y_k \in \{0,1\}$. The variable $y_k$ equals $1$ if candidate partition $k$ is selected, and $0$ otherwise. The vector of decision variables is denoted $\mathbf{y} = (y_0, y_1, \dots, y_{K-1})^\top$.

The requirement that exactly one partition is selected is expressed as: \begin{align} \sum_{k=0}^{K-1} y_k = 1. \end{align} Step 3 -- Penalty Term Expansion. We enforce the constraint using a quadratic penalty with weight $\lambda > 0$: \begin{align} P(\mathbf{y}) = \lambda \left( \sum_{k=0}^{K-1} y_k - 1 \right)^2. \end{align} Expanding the square yields: \begin{align} P(\mathbf{y}) = \lambda \left( \sum_{k=0}^{K-1} y_k^2 + \sum_{k \neq j} y_k y_j + 1 - 2\sum_{k=0}^{K-1} y_k \right). \end{align} Using the idempotent property of binary variables, $y_k^2 = y_k$, the expression simplifies to: \begin{align} P(\mathbf{y}) = \lambda \left( 1 - \sum_{k=0}^{K-1} y_k + \sum_{k \neq j} y_k y_j \right). \end{align} Noting that $\sum_{k \neq j} y_k y_j = 2 \sum_{0 \le k < j \le K-1} y_k y_j$, the penalty contribution becomes: \begin{align} P(\mathbf{y}) = \lambda - \lambda \sum_{k=0}^{K-1} y_k + 2\lambda \sum_{0 \le k < j \le K-1} y_k y_j. \end{align} Step 4 -- Combined Hamiltonian. Penalty Weight Justification

The penalty weight must be chosen as $\lambda > \max_{k} |S_k|$. This condition ensures that the energy penalty incurred by any infeasible assignment strictly exceeds the maximum possible gain achievable by the objective function. Specifically, if zero variables are selected, the penalty contributes $+\lambda$ to the energy. If two or more variables are selected, the quadratic term $2\lambda \sum_{k \max_k |S_k|$ guarantees that feasible solutions always have lower energy than infeasible ones.

Correctness Argument

Minimizing $H(\mathbf{y})$ over $\{0,1\}^K$ recovers the optimal partition because the penalty term is zero if and only if $\sum_k y_k = 1$, meaning all feasible solutions have unpenalized energy equal to $-\sum_k S_k y_k$. Infeasible solutions incur a penalty of at least $\lambda$, which by construction exceeds the maximum possible reduction in the objective term. Consequently, the global minimum of $H(\mathbf{y})$ must occur at a feasible point, and among feasible points, the minimum corresponds to the partition with the highest modularity-like score.
