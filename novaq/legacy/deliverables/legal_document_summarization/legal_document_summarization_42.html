Legal Document Extractive Summarization

Problem Statement

Given a legal document partitioned into $N$ candidate sentences, the goal is to construct an extractive summary of exactly $K$ sentences. Each sentence $i \in \{0, \dots, N-1\}$ is assigned an importance score $w_i \geq 0$. Additionally, each pair of distinct sentences $(i, j)$ with $0 \leq i < j \leq N-1$ is assigned a redundancy penalty $p_{ij} \geq 0$ reflecting the degree to which they cover overlapping legal points. The objective is to select a subset of exactly $K$ sentences that maximizes the total importance score while minimizing the total redundancy among the selected sentences.

Decision Variables

For each candidate sentence $i \in \{0, \dots, N-1\}$, we introduce a binary decision variable $x_i \in \{0, 1\}$. The variable $x_i$ equals $1$ if sentence $i$ is included in the summary, and $0$ otherwise.

The exactly-$K$ selection constraint is expressed algebraically as: \begin{align} \sum_{i=0}^{N-1} x_i = K. \end{align} Step 3. Following QUBO conventions, the equality constraint is enforced via a quadratic penalty term with weight $A > 0$: \begin{align} \mathcal{P}(x) = A \left( \sum_{i=0}^{N-1} x_i - K \right)^2. \end{align} Expanding the square yields: \begin{align} \mathcal{P}(x) = A \left( \sum_{i=0}^{N-1} x_i^2 + 2 \sum_{0 \leq i < j \leq N-1} x_i x_j - 2K \sum_{i=0}^{N-1} x_i + K^2 \right). \end{align} Applying the idempotent property $x_i^2 = x_i$ for binary variables simplifies the quadratic self-interaction terms: \begin{align} \mathcal{P}(x) = A \left( (1 - 2K) \sum_{i=0}^{N-1} x_i + 2 \sum_{0 \leq i < j \leq N-1} x_i x_j + K^2 \right). \end{align} Distributing $A$ gives the general penalty contribution to the Hamiltonian: \begin{align} \mathcal{P}(x) = A(1 - 2K) \sum_{i=0}^{N-1} x_i + 2A \sum_{0 \leq i < j \leq N-1} x_i x_j + A K^2. \end{align} Step 4. Combining the negated objective from Step 1 with the expanded penalty from Step 3 yields the full QUBO Hamiltonian $H(x)$: \begin{align} H(x) = \sum_{i=0}^{N-1} \left[ -w_i + A(1 - 2K) \right] x_i + \sum_{0 \leq i < j \leq N-1} \left[ p_{ij} + 2A \right] x_i x_j + A K^2. \end{align} Step 5. Reading off the coefficients from the general closed form of $H(x)$, the upper-triangular entries of the QUBO matrix $Q$ and the constant offset $c$ are: \begin{align} Q_{i,i} &= -w_i + A(1 - 2K), \quad \text{for } i \in \{0, \dots, N-1\}, \\ Q_{i,j} &= p_{ij} + 2A, \quad \text{for } 0 \leq i < j \leq N-1, \\ c &= A K^2. \end{align} The matrix is symmetric, so $Q_{j,i} = Q_{i,j}$ for $i > j$, and all unspecified entries are zero.

Penalty Weight Justification

The penalty weight $A$ must be chosen sufficiently large to ensure that any violation of the exactly-$K$ constraint results in an energy increase that strictly dominates any potential gain in the objective function. The maximum possible reduction in the original objective (or increase in the negated objective) from adding or removing a single sentence is bounded by $\max_{i} w_i$. Therefore, selecting $A > \max_{i} w_i$ guarantees that the quadratic penalty term outweighs any feasible objective improvement, forcing the optimizer to prioritize constraint satisfaction over marginal relevance gains.

Correctness Argument

Minimizing $H(x)$ over $\{0,1\}^N$ recovers the optimal summary because the penalty term is strictly non-negative and vanishes if and only if $\sum_{i} x_i = K$. For any feasible solution satisfying the constraint, $H(x)$ evaluates exactly to the negated objective function. For any infeasible solution, the penalty term $A(\sum_{i} x_i - K)^2$ adds a positive constant that, by the choice of $A$, exceeds the maximum possible difference between any two feasible objective values. Consequently, the global minimum of $H(x)$ must occur at a feasible point, and among feasible points, $H(x)$ is minimized exactly when the original objective is maximized.
